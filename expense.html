어떻게 제출하나요?

📷
① 사진 추가
사진 촬영 또는 갤러리에서 선택을 눌러 영수증 이미지를 가져옵니다. 갤러리에서는 한 번에 여러 장도 가능합니다.
📎
② 미리보기 확인
선택된 파일이 그리드로 표시됩니다. 잘못된 사진은 ✕ 버튼으로 제거하고, 사진을 누르면 크게 볼 수 있습니다.
🔍 탭하면 확대 미리보기
✏️
③ 메모 입력 (선택)
거래처, 용도, 출장 건명 등 관리자가 알아보기 쉽도록 짧게 적어둡니다. 비워두어도 업로드는 가능합니다.
📏 최대 500자
⬆️
④ 업로드
보라색 업로드 버튼을 누르면 사진이 한 장씩 서버에 저장되며, 진행 상황이 버튼에 (1/3) 형태로 표시됩니다.
✅ 완료 시 토스트 알림
📁
⑤ 내 영수증으로 확인
제출 결과는 내 영수증 화면에서 연·월 폴더로 모아 볼 수 있고, 잘못 올린 항목은 휴지통으로 삭제 가능합니다.
🗑️ 삭제는 본인 영수증만

제출한 영수증은 어떻게 정리되나요?

🗂️ 자동 분류
업로드된 영수증은 본인 ID 안에 연월 폴더(YYYY-MM)로 자동 정리됩니다. 직원이 따로 폴더를 만들 필요가 없습니다.
user-files / [ID] / receipts / 2026-04 /
🏷️ 파일명 규칙
파일명은 업로드한 날짜를 기준으로 자동 부여되며, 같은 날 여러 장을 올려도 순번이 자동으로 이어집니다.
[ID]_20260427_01.jpg
📋 관리자 일괄 다운로드
관리자(또는 회계 담당)는 영수증 조회 화면에서 직원별·월별로 ZIP 파일 일괄 다운로드가 가능합니다. 다운로드된 영수증은 따로 표시되어 누락 없이 정산할 수 있습니다.
💡 출장·외근 직후 그날 바로 제출하는 습관을 들이면 월말 정산이 훨씬 빨라집니다. 모바일에서도 동일하게 동작합니다.
