neothai-order.web.app
📱 ไม่ต้องติดตั้งผ่าน App Store เปิดเว็บไซต์ในเบราว์เซอร์ แล้วทำตามขั้นตอนสำหรับอุปกรณ์ของคุณเพื่อ เพิ่มไปยังหน้าจอหลัก หลังติดตั้งแล้ว สามารถเปิดแอปได้จากไอคอนเหมือนแอปทั่วไป
💻Chrome (PC)
เดสก์ท็อป Windows · macOS
  1. 1เปิด Chrome แล้วไปที่ neothai-order.web.app
  2. 2คลิกไอคอน ติดตั้ง ⊕ ทางขวาของแถบที่อยู่
    (ถ้าไม่เห็น คลิก ⋮ มุมขวาบน → "ติดตั้งแอป")
  3. 3ในหน้าต่างป๊อปอัป คลิก [ติดตั้ง]
  4. 4ไอคอนจะปรากฏบนเดสก์ท็อปและแถบงาน
✅ สามารถใช้งานผ่านบุ๊กมาร์กโดยไม่ต้องติดตั้งก็ได้
🤖Android
Samsung · Xiaomi · Android อื่นๆ
  1. 1เปิด Chrome แล้วไปที่ neothai-order.web.app
  2. 2แตะเมนู ⋮ มุมขวาบน
  3. 3แตะ [ติดตั้งแอป] หรือ [เพิ่มไปยังหน้าจอหลัก]
  4. 4แตะปุ่ม [ติดตั้ง]
  5. 5เปิดแอปจากไอคอนบนหน้าจอหลัก
💡 Samsung Internet ใช้วิธีเดียวกันได้
🍎iPhone (iOS)
iPhone · iPad
  1. 1ต้องใช้ Safari เท่านั้น ไปที่ neothai-order.web.app
  2. 2แตะปุ่ม แชร์ ⬆ ด้านล่างตรงกลาง
  3. 3เลื่อนหาและแตะ [เพิ่มไปยังหน้าจอหลัก]
  4. 4แตะ [เพิ่ม] มุมขวาบน
  5. 5เปิดแอปจากไอคอนบนหน้าจอหลัก
⚠ ใช้ Chrome ไม่ได้ — ต้องใช้ Safari เท่านั้น

📋 สิ่งที่ต้องตรวจสอบเมื่อเปิดแอปครั้งแรก

  • เข้าสู่ระบบด้วยรหัสพนักงาน (ขึ้นต้นด้วย T) และรหัสผ่าน
  • หากยังไม่มีบัญชี ลงทะเบียนที่แท็บ Register
  • อนุญาตการแจ้งเตือน (สำหรับการอนุมัติ/จัดส่ง)
  • เลือกภาษา: KO / EN / TH
  • อนุญาตตำแหน่งที่ตั้ง (เมื่อใช้แผนที่)
  • ตั้งชื่อเล่น · ลายเซ็น (ในตั้งค่าบัญชี)
