NeoBiotech Order App

주문·배송·고객 관리 통합 시스템 · 설치 안내

neothai-order.web.app
📱 앱 스토어 설치 불필요. 브라우저에서 웹사이트를 연 뒤, 아래 3가지 기기 중 본인의 기기에 맞는 방법으로 홈 화면에 추가하세요. 설치 후에는 일반 앱처럼 아이콘을 눌러 바로 실행됩니다.
💻Chrome (PC)
Windows · macOS 데스크탑
  1. 1Chrome 으로 neothai-order.web.app 접속
  2. 2주소창 오른쪽 설치 아이콘 ⊕ 클릭
    (안 보이면 우측 상단 ⋮ → "앱 설치")
  3. 3팝업에서 [설치] 클릭
  4. 4바탕화면·작업표시줄에 아이콘 생성 완료
✅ 설치하지 않고 즐겨찾기만 해도 사용 가능
🤖Android
삼성 · 샤오미 · 기타 Android
  1. 1Chrome 으로 neothai-order.web.app 접속
  2. 2우측 상단 ⋮ 메뉴 탭
  3. 3[앱 설치] 또는 [홈 화면에 추가] 탭
  4. 4[설치] 버튼 탭
  5. 5홈 화면에서 아이콘으로 실행
💡 삼성 인터넷 브라우저도 동일한 방법 사용 가능
🍎iPhone (iOS)
iPhone · iPad
  1. 1반드시 Safari 로 neothai-order.web.app 접속
  2. 2하단 중앙 공유 버튼 ⬆ 탭
  3. 3목록에서 [홈 화면에 추가] 탭
  4. 4우측 상단 [추가] 탭
  5. 5홈 화면에서 아이콘으로 실행
⚠ Chrome·크롬 앱 사용 불가 — Safari 필수

📋 설치 후 첫 실행 시 확인

  • 사번(T로 시작) · 비밀번호로 로그인
  • 계정이 없으면 Register 탭에서 등록
  • 알림 허용 (승인·배송 알림 수신)
  • 언어 설정: KO / EN / TH 중 선택
  • 위치 권한 허용 (지도 기능 사용 시)
  • 닉네임 · 서명 등록 (계정 설정)
